# Free TryHackMe Rooms

A topic-wise practice list of **728 free TryHackMe rooms** across 27 topics, from Linux basics to Active Directory, CTFs and SOC. Every link points to the official room on tryhackme.com. Nothing here bypasses a paywall.

## How to use this list

- Work through the topics in order, or jump to the topic you need from the table of contents.
- Tick a room (`- [x]`) when you finish it to track your progress. Edit the file in your own copy of the repo to save the ticks.
- TryHackMe can move a room from free to subscriber-only at any time. If a room asks for a subscription, it is no longer free: skip it and, if you like, delete its line.
- Free accounts have usage limits (for example on in-browser AttackBox time). Check TryHackMe for the current limits.
